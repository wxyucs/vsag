# 场景化最佳实践

[最佳实践（总览）](../resources/best_practices.md)汇总了选型、构建、搜索、调优、部署等通用建议。
本系列在此基础上，针对**具体落地场景**提供更深入的端到端方案：背景权衡、推荐架构、可运行的
参数配置、调优与排错清单，并对照业界向量数据库的常见做法，帮助你少走弯路。

每一篇都遵循同样的结构：

- **什么时候用** —— 触发该场景的数据规模、内存预算、延迟 / QPS、成本等信号；
- **业界设计空间** —— 中立地梳理主流方案，再落到 VSAG 的对应实现；
- **推荐方案** —— 可直接复制的 JSON 配置与参数表；
- **调优与排错** —— 召回 / 延迟 / 内存三个维度的对症处方。
